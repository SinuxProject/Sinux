# اگر فقط یک خط چشمکزن بالای صفحه میبینید

نسخهٔ `1.1.0` (بیلد رفع اشکال) این مشکل را برطرف کرده است. حتماً از
**همین فایل ISO جدید** استفاده کنید، نه نسخهٔ قدیمی `1.0.0`.

## علت چی بود

در بوت قبلی خط فرمان کرنل این بود:

```
console=tty0 console=ttyS0,115200
```

در لینوکس، `/dev/console` به **آخرین** `console=` وصل میشود — یعنی پورت
سریال `ttyS0`. روی کامپیوتری که پورت COM ندارد، تمام پیامها و کل رابط
نصبکننده به دستگاهی نوشته میشد که کسی آن را نمیبیند؛ نتیجه دقیقاً همان
صفحهٔ سیاه با یک کرسر چشمکزن گوشهٔ بالا سمت چپ بود. ضمن اینکه `quiet`
هم تمام پیامهای پیشرفت بوت را مخفی میکرد.

## چه تغییر کرد

- گزینههای پیشفرض منو فقط `console=tty0` میگیرند → رابط روی مانیتور/VGA/EFI
  framebuffer نمایش داده میشود.
- `/init` کنسول واقعی را از `/sys/class/tty/console/active` تشخیص میدهد و
  ورودی/خروجی نصبکننده را **صریحاً** به همان دستگاه وصل میکند
  (`SINUX_CONSOLE`).
- `quiet` حذف شد و `loglevel=4` جایگزین شد: اگر خطایی پیش بیاید دیده میشود،
  ولی صفحه از پیامهای اضافی پر نمیشود.
- قبل از باز کردن initramfs، GRUB یک خط
  `Loading Sinux Installer 1.1.0 ... please wait` چاپ میکند تا معلوم شود بوت
  شروع شده (باز کردن ۳۴ مگابایت روی USB کند ممکن است چند ثانیه طول بکشد).
- یک گزینهٔ امن اضافه شد: **Safe text mode (VGA only, no dialog)** با
  `nomodeset` و `sinux.nodialog=1` — بدون ncurses، بدون سریال، بدون
  modesetting درایور گرافیک.

## قدم به قدم

1. ISO جدید را دوباره روی USB بریزید (فایل قدیمی را کامل حذف کنید):
   ```bash
   sudo dd if=Sinux-Installer-1.1.0-x86_64.iso of=/dev/sdX bs=4M conv=fsync status=progress
   ```
2. **Secure Boot را خاموش کنید.**
3. بوت کنید. منوی GRUB باید ۸ گزینه داشته باشد. اگر منو را اصلاً نمیبینید،
   مشکل از GRUB/رسانه است: یک بار ISO را دوباره بریزید، پورت USB دیگر را
   امتحان کنید، و در فرمور حالت UEFI و Legacy/CSM را عوض کنید.
4. منو بالا آمد ولی بعدش باز هم فقط کرسر چشمکزن ماند؟ گزینهٔ
   **Safe text mode (VGA only, no dialog)** را انتخاب کنید. این گزینه
   `nomodeset` و رابط متنی ساده دارد و روی کارتهای گرافیکی مشکلدار هم کار
   میکند.
5. اگر پیام `Loading Sinux Installer ... please wait` آمد و بعد هیچی نشد،
   چند ثانیهٔ بیشتر صبر کنید (باز کردن initramfs)، سپس گزینهٔ
   **Verbose / debug (serial, all messages)** را امتحان کنید تا پیامهای کرنل
   را ببینید.
6. همچنان گیر کرد؟ گزینهٔ **Rescue shell** را بگیرید و بزنید:
   ```sh
   cat /proc/cmdline
   cat /sys/class/tty/console/active
   cat /var/log/sinux-install.log
   ```

## پارامتر دستی

میتوانید در منوی GRUB با `e` خط `linux` را ویرایش کنید:

```
console=tty0                     مانیتور معمولی (پیشفرض)
console=ttyS0,115200             فقط سریال
sinux.nodialog=1                 رابط متنی ساده، بدون dialog
sinux.debug=1                    لاگ کامل ماژولها و کرنل
nomodeset                        اگر درایور گرافیک هنگ میکند
```

## نکته

این یک لینوکس زندهٔ مینیمال فقط بهعنوان **وسیلهٔ نصب** است؛ چیزی که روی
دیسک نصب میشود کرنل **سینوکس** است (یک کرنل مستقل از صفر، نه لینوکس).

## بعد از نصب دوباره منوی نصبکننده بالا میآید / ترمینال سیستم نمیآید

این هم رفع شد (همان بیلد آخر). دو علت داشت:

1. نصب تعاملی بعد از `INSTALL COMPLETE` **ریبوت نمیکرد** و مستقیم برمیگشت سر
   منوی اصلی نصبکننده.
2. وقتی دستی «Reboot» میزدید، فرمور همچنان **USB را اول** بوت میکرد، پس GRUB
   همان ISO بالا میآمد.

الان:

- بعد از اتمام نصب پیام **«USB نصب را جدا کنید، سپس OK بزنید»** میآید و دستگاه
  بهصورت خودکار ریبوت میشود. سیستم زنده کاملاً در RAM است، پس کشیدن USB در همان
  لحظه بیخطر است.
- منوی GRUB روی ISO فایل نشانگر `/etc/sinux/install-info.json` را روی دیسکها
  جستجو میکند. اگر سیستم نصبشده پیدا شد، گزینهٔ
  **Boot installed Sinux from this disk (system terminal)** بهعنوان **پیشفرض**
  انتخاب میشود و تایماوت به ۵ ثانیه کم میشود. یعنی **حتی اگر USB را نکشید**
  ترمینال `root@sinux:/root#` بالا میآید، نه نصبکننده.
- در UEFI یک ورودی NVRAM واقعی با `efibootmgr` ساخته میشود، `BootNext` روی آن
  تنظیم و `Sinux` اول `BootOrder` قرار میگیرد تا فرمورهایی که مسیر
  `EFI/BOOT/BOOTX64.EFI` روی دیسک ثابت را نادیده میگیرند هم درست بوت کنند.
- اگر خواستید دوباره نصب کنید یا از ابزارها استفاده کنید، کافی است در همان منو
  یکی از ۸ گزینهٔ نصبکننده را دستی انتخاب کنید.

> روی کنسول سریال ممکن است قبل از منو یک خط
> `error: no such device: /etc/sinux/install-info.json` ببینید. این فقط نتیجهٔ
> جستجوی سیستم نصبشده روی دستگاه تازه است، **خطا نیست** و روی صفحهٔ VGA پاک
> میشود.

تستهای T14 (USB وصل → ترمینال سیستم)، T15 (نصب تعاملی → ریبوت خودکار) و
T16 (UEFI ← `BootNext`) این رفتار را تأیید میکنند: ۷۴ تست، ۷۴ پاس، ۰ شکست.
